## Домашние задания

В курсе два домашних задания. В ДЗ 1 и ДЗ 2 есть основная часть и бонусные задания.

## Оценивание

Пусть $H_1$ и $H_2$ — баллы за основные части ДЗ, а $B_1$ и $B_2$ — бонусные баллы. Бонусы прибавляются к сумме баллов перед делением на два.

$$
\mathrm{ДЗ} = \frac{H_1 + H_2 + B_1 + B_2}{2}.
$$

Экзамен оценивается от 0 до 10. Домашние задания дают 40% итоговой оценки, экзамен — 60%. Если средний балл за ДЗ с бонусами выше 12, в итоговой формуле используется 12.

$$
\mathrm{Итог} = \min\left(10,\ 0.4 \cdot \min(12, \mathrm{ДЗ}) + 0.6 \cdot \mathrm{Экз}\right).
$$

Несданное задание даёт 0 баллов. Промежуточные значения сохраняют точность, итоговая оценка округляется арифметически.

| Основные ДЗ | Сумма бонусов | ДЗ с учётом ограничения | Экзамен | Итог до округления |
|---|---:|---:|---:|---:|
| 8, 8 | 0 | 8 | 7 | 7.4 |
| 10, 10 | 6 | 12 | 8 | 9.6 |
| 10, 0 | 0 | 5 | 6 | 5.6 |

## Окружение

Для запуска семинаров подойдёт Python 3.11 или 3.12. В активированном виртуальном окружении выполните

```bash
python -m pip install -r requirements.txt
jupyter lab
```

Для примеров из третьей лекции установите PyTorch под свою ОС и устройство. [Официальная инструкция](https://pytorch.org/get-started/locally/)

Семинары по калибровке и гомографии при первом запуске скачивают примеры изображений OpenCV.

## Подготовка изменений

```bash
python -m pip install -r requirements-dev.txt
pre-commit install
pre-commit run --all-files
```

Хуки проверяют структуру ноутбуков и удаляют сохранённые выводы и счётчики выполнения. Если хук изменил ноутбук, добавьте обновлённый файл через `git add` и повторите коммит.
